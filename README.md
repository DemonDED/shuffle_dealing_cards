# Программа «Колода карт» (Shuffle & Deal)

Эта консольная программа на языке C моделирует перетасовку стандартной колоды из 52 карт и последующую «раздачу» (вывод) всех карт в случайном порядке.
Проект создан в учебных целях для демонстрации работы с двумерными массивами, указателями на строки, генератором псевдослучайных чисел и организацией кода с использованием функций.

🃏 Как это работает

   + Колода представлена двумерным массивом `deck[4][13]`, где строки соответствуют мастям, а столбцы — достоинствам карт.

   + Функция `shuffle()` заполняет массив числами от 1 до 52, размещая каждое число в случайную свободную ячейку. Это гарантирует, что все карты будут расположены в случайном порядке (каждая карта встречается ровно один раз).

   + Функция `deal()` проходит по числам от 1 до 52 и для каждого числа находит соответствующую позицию в массиве, после чего выводит название масти и достоинства карты. Вывод форматируется так, чтобы в каждой строке было по две карты.

🛠️ Компиляция и запуск

В проекте предусмотрен Makefile для удобной сборки. Для компиляции понадобится компилятор `gcc` и утилита `make`.

   + Сборка оптимизированной версии (с флагами `-Wall -Werror -Wextra`):
```bash
    make
```
    Будет создан исполняемый файл main.bin.

   + Сборка отладочной версии (с флагом `-g` для отладчика):
```bash
    make debug
```
    Исполняемый файл также называется main.bin, но содержит отладочную информацию.

После сборки запустите программу:
```bash
./main.bin
```
